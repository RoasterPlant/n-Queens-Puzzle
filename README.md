What is the maximum number of queens that can be placed on a chessboard without any two queens attacking each other? The program gives you the answer - 8 and possible positions (one of many) of queens on the chessboard. See https://en.wikipedia.org/wiki/Eight_queens_puzzle.

To run the project, you need four files: 2 Python files - RunQueens.py and Queens.py and 2 data files: Config.csv and Input.csv.
The directory structure is the following:
Queens -> PythonCode -> Python files.
Queens -> Problems -> p001 -> data files.
